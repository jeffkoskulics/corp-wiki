Click **Edit** at the bottom-right of any page. Pages use Obsidian-flavoured Markdown:

- `[[Page]]`, `[[Page|label]]`, `[[Page#Heading]]` link to other pages; type `[[` for suggestions.
- `![[Page]]` embeds another page.
- `> [!tip]` starts a callout.

**Rename** a page from the editor: every link pointing to it is updated in the same commit.
Every save is a Git commit, so the full history is kept and any change can be reverted.
